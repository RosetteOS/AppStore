Using the rosetteos-app command

Manage everything straight from SSH or via Klipper G-code Macros in Mainsail / Fluidd.

1. Discovery

List & Check Updates

View all installed and available applications along with version status:

rosetteos-app list

Refresh catalog from remote repository:

rosetteos-app update
2. Installation

Install Applications & Plugins

Install and automatically configure Moonraker & Klipper includes:

rosetteos-app install fluidd

Install and auto-activate in one step:

rosetteos-app install fluidd --activate
3. Switching

Dynamic Web & Touch UI Switcher

Switch default web frontend (Mainsail ↔ Fluidd):

rosetteos-app set-active-web fluidd

Switch touchscreen display UI (GuppyScreen ↔ HelixScreen):

rosetteos-app set-active-touch helixscreen
4. Maintenance

Upgrade & Removal

Upgrade all installed apps to the latest versions:

rosetteos-app upgrade --all

Cleanly uninstall with automatic fallback to defaults:

rosetteos-app remove fluidd

Add Your App to the Catalog

Adding a new UI, plugin, or tool requires no firmware rebuilding. Simply open a pull request adding a JSON manifest to apps/<category>/<app_id>.json in our GitHub repository.
